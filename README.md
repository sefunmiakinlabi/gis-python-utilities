# Geospatial Workflows for Environmental Monitoring & Agriculture

This repository contains practical scripts developed for geospatial data automation, agricultural plot polygon generation, and satellite land-use/land-cover (LULC) classification across workflows in **Python (ArcPy)**, **R**, and **Google Earth Engine (JavaScript)**.

Compiled as part of a portfolio .
